# 全类舞蹈报名系统 - 需求文档

## 1. 项目背景

### 1.1 项目概述

本项目为省级大学舞蹈比赛搭建统一的在线报名系统。举办一次省级舞蹈比赛，所有想要参赛的大学都需要在本系统进行报名，组委会通过系统审核各学校的报名信息。

### 1.2 系统边界

本系统为**纯报名系统**，仅覆盖从报名到审核完成的流程。现场比赛及打分环节不在本系统范围内。

### 1.3 赛制流程

```
学校在线报名 → 组委会在线审核 → 现场比赛（线下，本系统不涉及）
```

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 学校端（school） | 各参赛大学，负责在线报名 |
| 组委会端（committee） | 审核报名 |
| 管理员端（admin） | 全面管理：赛事配置、账号管理、数据导出、系统设置 |

## 3. 比赛规则

### 3.1 比赛类别与人数规定

| 类别 | 说明 | 人数要求 |
|------|------|----------|
| 独舞 | 单人表演 | 1人 |
| 双人舞 | 两人配合表演 | 2人 |
| 三人舞 | 三人配合表演 | 3人 |
| 群舞 | 集体表演 | 6-16人 |
| 集体舞 | 大型集体表演 | 16-30人 |

### 3.2 舞种与可选类别

| 舞种 | 可选类别 |
|------|----------|
| 民族民间舞 | 独舞、双人舞、三人舞、群舞、集体舞 |
| 古典舞 | 独舞、双人舞、三人舞、群舞、集体舞 |
| 现代舞 | 独舞、双人舞、三人舞、群舞、集体舞 |
| 当代舞 | 独舞、双人舞、三人舞、群舞、集体舞 |
| 芭蕾舞 | 独舞、双人舞、三人舞、群舞、集体舞 |
| 拉丁舞 | 独舞、双人舞、群舞（6-12人） |
| 街舞 | 独舞、群舞（6-20人）、集体舞（16-30人） |
| 国标舞 | 双人舞、群舞（6-12人） |

### 3.3 节目时长限制

| 类别 | 时长上限 |
|------|----------|
| 独舞 | 不超过 5 分钟 |
| 双人舞 | 不超过 5 分钟 |
| 三人舞 | 不超过 6 分钟 |
| 群舞 | 不超过 8 分钟 |
| 集体舞 | 不超过 10 分钟 |

### 3.4 参赛人员信息要求

每位参赛人员必须填写以下信息：

| 字段 | 必填 | 格式要求 | 说明 |
|------|------|----------|------|
| 姓名 | 是 | 2-10个中文字符 | |
| 性别 | 是 | 男/女 | |
| 身份证号 | 是 | 18位身份证号 | 用于身份核验，同一赛事中同一身份证号不可重复出现在不同学校 |
| 学号 | 是 | 文本 | 必须为本校在籍学生 |
| 院系 | 是 | 文本 | 所在院系名称 |
| 联系电话 | 否 | 11位手机号 | |

### 3.5 节目信息要求

每个报名节目必须填写以下信息：

| 字段 | 必填 | 格式要求 | 说明 |
|------|------|----------|------|
| 节目名称 | 是 | 2-30个字符 | 同一学校同一组别下不可重名 |
| 比赛类别 | 是 | 独舞/双人舞/三人舞/群舞/集体舞 | 选择后需满足对应人数要求，且该舞种必须支持该类别 |
| 节目时长 | 是 | 分:秒格式，如 4:30 | 不得超过对应类别的时长上限 |
| 节目视频 | 是 | MP4格式，不超过500MB | 每个节目必须上传一个视频 |
| 编导姓名 | 是 | 文本 | 节目编导 |
| 伴奏说明 | 否 | 文本，不超过200字 | 如需特殊伴奏可备注 |

### 3.6 报名规则

| 规则 | 说明 |
|------|------|
| 配额限制 | 每个学校在各舞种下有配额上限，由管理员通过配额表分配，超过配额不可报名 |
| 组别上限 | 每个组别有总节目数上限，达到后该组别关闭报名 |
| 截止时间 | 超过报名截止时间不可提交 |
| 人数校验 | 参演人员数量必须符合所选比赛类别的人数要求（如群舞必须6-16人） |
| 时长校验 | 节目时长不得超过所选比赛类别的时长上限 |
| 人员重复 | 同一参赛人员（同学号）可参与同一学校的多个节目 |
| 节目唯一 | 同一学校 + 同一组别 + 同一节目名称不可重复提交 |
| 视频必传 | 每个节目必须上传一个视频，格式MP4，大小不超过500MB |
| 联系人前置 | 学校联系人信息（姓名、电话）未填写时不可报名 |

## 4. 功能需求

### 4.1 管理员端

#### 4.1.1 赛事管理

| 需求项 | 说明 |
|--------|------|
| 创建赛事 | 填写赛事名称、简介、报名起止时间、比赛起止日期、比赛地点 |
| 编辑赛事 | 仅草稿/报名中状态可编辑，已截止/已结束不可编辑 |
| 变更状态 | 草稿 → 报名中 → 已截止 → 已结束，只能按顺序推进，不可回退 |
| 删除赛事 | 仅草稿状态可删除 |
| 赛事列表 | 分页展示所有赛事，显示状态、报名时间、报名人数等 |

#### 4.1.2 组别管理

| 需求项 | 说明 |
|--------|------|
| 添加组别 | 为赛事配置组别，每个组别对应一个舞种，设置该组别总节目数上限 |
| 删除组别 | 仅草稿状态赛事可删除组别，报名中后不可删除 |

**约束**：同一赛事下，同一舞种只能创建一个组别。

#### 4.1.3 配额管理

每个学校有一份配额表，规定该校在各舞种下可报名的节目数量，通过 Excel 导入。

| 需求项 | 说明 |
|--------|------|
| Excel 导入配额表 | 上传 Excel 批量设置各学校在赛事中各舞种的配额 |
| 查看配额 | 按学校查看其配额表（各舞种的配额数和已用数） |
| 手动编辑配额 | 对单个学校单个舞种的配额逐条调整 |

**配额表 Excel 格式**：

| 学校编码 | 学校名称 | 民族民间舞 | 古典舞 | 现代舞 | 当代舞 | 芭蕾舞 | 拉丁舞 | 街舞 | 国标舞 |
|----------|----------|------------|--------|--------|--------|--------|--------|------|--------|
| S001 | XX大学 | 3 | 2 | 1 | 2 | 1 | 2 | 1 | 0 |
| S002 | YY大学 | 2 | 1 | 2 | 1 | 0 | 1 | 2 | 1 |

**说明**：列头为舞种名称，值为该校在该舞种下最多可报的节目数。值为 0 或未填写表示该校在该舞种下不可报名。

#### 4.1.4 账号管理

| 需求项 | 说明 |
|--------|------|
| Excel 导入学校账号 | 字段：学校编码、学校名称、初始密码 |
| Excel 导入组委会账号 | 字段：姓名、手机号、初始密码 |
| 账号列表 | 分页展示，支持按角色、名称、状态筛选 |
| 启用/禁用账号 | 禁用后该账号无法登录 |
| 重置密码 | 将账号密码重置为默认密码 |

**说明**：学校数据通过 Excel 批量导入，学校编码由上级统一分配，为唯一标识。

#### 4.1.5 数据导出

| 需求项 | 说明 |
|--------|------|
| 导出报名数据 | 按赛事、按组别导出全部报名记录为 Excel（含学校信息、节目信息、参演人员信息） |
| 导出审核结果 | 导出各学校的审核状态汇总 |

#### 4.1.6 系统设置

| 需求项 | 说明 |
|--------|------|
| 舞种字典 | 增删改舞种，每个舞种需配置可选的比赛类别 |
| 比赛类别字典 | 管理比赛类别（独舞/双人舞/三人舞/群舞/集体舞）及各类别的人数范围和时长上限 |

### 4.3 学校端

#### 4.3.1 赛事浏览

| 需求项 | 说明 |
|--------|------|
| 赛事列表 | 展示当前可报名的赛事（报名中状态） |
| 赛事详情 | 查看赛事简介、时间、地点、全部组别列表、本校各舞种配额及已用数 |

#### 4.3.2 在线报名

**前置条件**：
- 赛事状态为报名中
- 学校联系人信息已填写（联系人姓名、联系电话必填）

**报名步骤**：

1. **选择赛事** → 进入赛事详情页，查看组别列表和本校配额
2. **选择组别（舞种）** → 展示全部组别，显示本校配额已用数/配额总数、组别已报数/上限，配额用完或组别已满置灰不可选
3. **选择比赛类别** → 根据所选舞种展示可选的比赛类别（独舞/双人舞/三人舞/群舞/集体舞）
4. **填写节目信息** → 节目名称、节目时长（分:秒）、编导姓名、伴奏说明（选填）
5. **上传节目视频** → 上传 MP4 视频文件，不超过 500MB
6. **添加参演人员** → 从本校人员库选择或新增，人数必须符合所选比赛类别的要求。每位人员需填写：姓名、性别、身份证号、学号、院系、联系电话（选填）
7. **确认提交** → 展示报名信息摘要（节目信息、视频、参演人员列表），确认后提交

**系统校验规则**（提交时自动检查）：

| 校验项 | 规则 | 不通过提示 |
|--------|------|------------|
| 配额检查 | 该校在该舞种的已报数 < 配额数 | "该校在XX舞种的配额已用完" |
| 组别上限 | 该组别已报数 < 总上限 | "该组别报名已满" |
| 截止时间 | 当前时间 < 报名截止时间 | "报名已截止" |
| 节目名称 | 同校同组别下不重名 | "该节目名称已存在，请修改" |
| 人数检查 | 符合所选比赛类别的人数要求 | "XX类别需要N-M人，当前X人" |
| 时长检查 | 不超过所选类别的时长上限 | "XX类别时长上限为X分钟" |
| 视频检查 | 已上传且为MP4、不超过500MB | "请上传MP4格式视频，大小不超过500MB" |
| 身份证号 | 18位合法身份证号 | "身份证号格式不正确" |
| 学号必填 | 每位参演人员必须填写学号 | "参演人员XX的学号未填写" |
| 联系人检查 | 学校联系人姓名和电话已填写 | "请先完善学校联系人信息" |

#### 4.3.3 报名管理

| 报名状态 | 学校可执行操作 |
|----------|---------------|
| 待审核（pending） | 查看、撤销（删除）、修改节目信息/视频/人员 |
| 已通过（approved） | 仅可查看（含在线观看视频），不可修改和撤销 |
| 已驳回（rejected） | 查看驳回原因、修改后重新提交（变回待审核）、可替换视频、删除 |

#### 4.3.4 个人中心

| 需求项 | 说明 |
|--------|------|
| 学校信息（只读） | 学校编码、学校名称（由导入数据决定，不可修改） |
| 修改联系人 | 联系人姓名、联系电话 |
| 修改补充信息 | 通讯地址、邮箱 |
| 修改密码 | 旧密码 + 新密码 |
| 人员库管理 | 查看、新增、编辑、删除本校参演人员（供报名时快速选择复用） |

**人员库字段**：姓名、性别、身份证号、学号、院系、联系电话

### 4.4 通知系统

#### 4.4.1 通知触发场景

| 触发事件 | 通知对象 | 通知内容 |
|----------|----------|----------|
| 报名提交成功 | 学校 | "您的节目《XXX》已成功提交，等待审核" |

| 审核驳回 | 学校 | "您的节目《XXX》被驳回，原因：XXX" |

#### 4.4.2 通知展示

- 顶部导航栏显示未读通知数量角标
- 通知列表页：按时间倒序，支持标记已读/全部已读
- 点击通知跳转到相关页面（报名记录或赛事详情）

**注意**：部分舞种的群舞人数范围有自定义覆盖（如拉丁舞群舞6-12人、街舞群舞6-20人），校验时以舞种配置的可选类别为准，无自定义则使用比赛类别字典的默认值。

## 6. 业务规则

### 6.1 报名状态流转

```
学校提交 → 待审核（pending）
              │
              ├── 组委会通过 → 已通过（approved）
              │
              └── 组委会驳回 → 已驳回（rejected）
                                    │
                                    ├── 学校修改后重新提交 → 待审核（pending）
                                    │
                                    └── 学校删除 → 记录移除
```

### 6.2 状态操作约束

| 状态 | 约束 |
|------|------|
| 待审核 | 学校可修改所有信息（节目信息、视频、人员），可撤销删除 |
| 已通过 | 不可修改、不可撤销，仅可查看 |
| 已驳回 | 学校可修改所有信息后重新提交（回到待审核）、可删除 |

### 6.3 组委会审核范围

组委会成员可查看全部报名记录，按组别（舞种）筛选审核。

### 6.4 账号数据来源

- 学校账号：通过 Excel 批量导入，学校编码为唯一标识
- 组委会账号：通过 Excel 批量导入
- 学校名称由导入数据决定，学校端不可修改

### 6.5 人数校验规则

提交报名时，系统根据所选比赛类别自动校验参演人员数量：

| 场景 | 校验逻辑 |
|------|----------|
| 选择"独舞" | 必须恰好 1 人 |
| 选择"双人舞" | 必须恰好 2 人 |
| 选择"三人舞" | 必须恰好 3 人 |
| 选择"群舞" | 必须 6-16 人（部分舞种有自定义范围） |
| 选择"集体舞" | 必须 16-30 人 |

**舞种自定义覆盖**：

| 舞种 | 类别 | 自定义人数范围 |
|------|------|----------------|
| 拉丁舞 | 群舞 | 6-12人 |
| 街舞 | 群舞 | 6-20人 |
| 国标舞 | 群舞 | 6-12人 |

### 6.6 时长校验规则

提交报名时，系统根据所选比赛类别自动校验节目时长：

| 类别 | 时长上限 |
|------|----------|
| 独舞 | 5分钟 |
| 双人舞 | 5分钟 |
| 三人舞 | 6分钟 |
| 群舞 | 8分钟 |
| 集体舞 | 10分钟 |
